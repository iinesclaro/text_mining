# Decoding the Rhythms of Emotion: A Sentimental Journey Through Music Genres

Group Project for **Text Mining 2026/2027**

## Overview
In  the  vast  world  of  music,  lyrics  often  serve  as  a  mirror,  reflecting  the emotions, thoughts, and narratives of the artist. These lyrical themes can vary  significantly  across  different  music  genres,  painting  a  diverse emotional landscape. This project aims to explore this landscape through the lens of Natural Language Processing (NLP).
